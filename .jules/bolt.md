## 2024-05-24 - Raw Node.js HTTP Server Optimizations
**Learning:** In raw Node.js HTTP servers (like `http.createServer`), pre-allocating static responses as `Buffer` objects avoids repeated string encoding overhead. Furthermore, using `res.writeHead()` to send status and headers in a single operation is measurably faster than setting `res.statusCode` and `res.setHeader` individually. Explicitly calculating and setting the `Content-Length` header (e.g., `responseBody.length`) also optimizes client-side connection handling. These changes yielded a ~16.7% increase in Requests per Second in a minimal benchmark.
**Action:** When working with raw Node.js `http` module servers, always pre-allocate static response buffers, compute `Content-Length` manually, and use `res.writeHead()` for combined status and header sending to maximize throughput.
